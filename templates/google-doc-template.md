## Cómo Usar Esta Plantilla

### Paso 1: Crear el Google Doc
1. Copia este contenido a un nuevo Google Doc
2. Aplica los estilos recomendados
3. Añade tu logo/branding si lo deseas

### Paso 2: Obtener el Template ID
1. Abre el documento en Google Docs
2. Copia el ID de la URL: `docs.google.com/document/d/TEMPLATE_ID/edit`
3. Usa este ID en la variable `GOOGLE_DOC_TEMPLATE_ID` en n8n

### Paso 3: Compartir Permisos
1. Click en "Compartir"
2. Cambia a "Cualquier persona con el enlace puede ver"
3. O dale permisos específicos a la cuenta de servicio de Google que usas en n8n

### Paso 4: Probar
1. Ejecuta el workflow con datos de prueba
2. Verifica que todos los placeholders se reemplazan correctamente
3. Revisa el formato del PDF generado
