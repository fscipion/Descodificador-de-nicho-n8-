## 📝 Formato Recomendado en Google Docs

### Estilos Sugeridos

**Título Principal** ("DESCODIFICADOR DE NICHO™"):
- Fuente: Montserrat Bold, 32pt
- Color: #667eea (morado profesional)
- Alineación: Centro

**Títulos de Sección** (## con emojis):
- Fuente: Montserrat SemiBold, 22pt
- Color: #2c3e50
- Alineación: Izquierda

**Subtítulos** (###):
- Fuente: Montserrat Medium, 16pt
- Color: #34495e

**Texto Normal**:
- Fuente: Open Sans Regular, 11pt
- Color: #333333
- Interlineado: 1.5

**Texto Destacado** (las 3 declaraciones principales):
- Fuente: Open Sans Bold, 13pt
- Color: #2c3e50
- Background: #f8f9fa (gris muy claro)
- Padding: 15px

### Elementos Visuales

- **Líneas separadoras**: Color gris claro #e0e0e0, 1pt
- **Cajas importantes**: Fondo #f8f9fa, borde izquierdo #667eea de 4pt
- **Emojis**: Usar en títulos de sección para mejor escaneabilidad
- **Espaciado**: Generoso entre secciones (doble espacio)

### Márgenes y Espaciado

- Márgenes: 2.5 cm todos los lados
- Espaciado entre secciones principales: 2 líneas
- Espaciado entre párrafos: 0.8 líneas
- Sangría: 0 (sin sangría en primera línea)

## Cómo Usar Esta Plantilla

### Paso 1: Crear el Google Doc
1. Copia este contenido a un nuevo Google Doc
2. Aplica los estilos recomendados (títulos, fuentes, colores)
3. Añade tu logo/branding en el header si lo deseas
4. Ajusta colores según tu identidad de marca

### Paso 2: Obtener el Template ID
1. Abre el documento en Google Docs
2. Copia el ID de la URL:
   `docs.google.com/document/d/TEMPLATE_ID/edit`
3. Usa este ID en la variable `GOOGLE_DOC_TEMPLATE_ID` en n8n

### Paso 3: Compartir Permisos
1. Click en "Compartir"
2. Cambia a "Cualquier persona con el enlace puede ver"
3. O dale permisos específicos a la cuenta de servicio de Google que usas en n8n

### Paso 4: Probar
1. Ejecuta el workflow con datos de prueba
2. Verifica que:
   - Todos los placeholders se reemplazan correctamente
   - El formato se mantiene legible
   - Los 3 outputs de Claude se ven bien
   - El PDF generado es profesional

## Tips para el PDF Final

### Optimización
- El PDF final pesará ~500KB-1MB
- Gmail acepta hasta 25MB (no hay problema)
- WhatsApp acepta hasta 100MB (no hay problema)

### Formato
- El PDF mantendrá exactamente el formato del Google Doc
- Las fuentes se incrustarán automáticamente
- Los colores se preservarán

### Testing
Genera un PDF de prueba:
1. File > Download > PDF Document
2. Abre en varios dispositivos (desktop, tablet, móvil)
3. Verifica que sea legible en todos
4. Ajusta tamaños de fuente si es necesario
